Fyolo 用同一个构建同时运行在 Apple 芯片和 Intel 的 Mac 上。安装只需一条 Homebrew 命令——不用注册账号，
也没有许可证密钥要填。

<Callout type="note" title="开始之前">
  Fyolo 需要 macOS 14 或更高版本，Apple 芯片和 Intel 的 Mac 都可以。它托管你已经
  装好的 Agent 命令行工具，本身不打包它们。
</Callout>

## 你需要什么

| | |
| --- | --- |
| **macOS** | 14（Sonoma）或更高版本，Apple 芯片和 Intel 都可以——同一个通用构建 |
| **Homebrew** | [brew.sh](https://brew.sh)，或者改为下载磁盘映像 |
| **账号** | 不需要。没有登录、没有许可证密钥，也没有支付后端 |
| **Agent 命令行工具** | 你本来在用的那些，`claude`、`codex` 之类。Fyolo 托管它们，不附带它们 |
| **想用另一台机器** | 任何你已经能 `ssh` 上去的机器。Fyolo 读你的 `~/.ssh/config`，不以 root 身份装任何东西 |

## 用 Homebrew 安装

```sh
brew install --cask fl0wo/tap/fyolo
```

Homebrew 会从 GitHub 下载最新版本，把 Fyolo 放进 **应用程序** 文件夹，并清除 macOS
给下载文件打上的隔离标记。Fyolo 用的是临时签名（ad-hoc），没有经过 Apple 公证，
少了这一步 Gatekeeper 会拒绝打开它。

## 确认装好了

启动 Fyolo，你应该会看到欢迎界面，**打开项目**是那个主按钮。整个安装就到这儿——没有设置
向导，没有账号步骤，第一个会话之前也没有什么要配置的。

首次启动时，Fyolo 会问你一次要不要让 Agent 互相协作——也就是**会话控制**，它会装一个小
技能，教它们 `fyolo sessions` 这些命令。**Agent 实时状态**（侧栏状态点背后的那些 hooks）
是同一个标签页上另一个开关；当侧栏看到有 Agent 在跑时会提示你打开。两个都是可选的，也都
可以关掉；参见[状态 hooks 与会话控制](/zh-CN/docs/session-control)。

如果你本来就在用 [Ghostty](https://ghostty.org)，那就没什么要挑的：Fyolo 会在首次启动时
读你的 `~/.config/ghostty/config`，用你在那里选好的字体和主题开始。

## 改为下载磁盘映像

如果你不想用 Homebrew，每个版本都会把磁盘映像附在它的
[GitHub 发布页](https://github.com/fl0wo/fyolo/releases/latest)上。

1. 从最新版本下载 `fyolo.dmg`。
2. 打开它，把 **Fyolo** 拖进 **应用程序** 文件夹。
3. 启动它。第一次启动时，macOS 会因为应用未经公证而拦下它：打开
   **系统设置 ▸ 隐私与安全性**，在关于 Fyolo 的提示旁点 **仍要打开**。运行
   `xattr -dr com.apple.quarantine /Applications/fyolo.app` 效果相同。

## 保持最新

```sh
brew upgrade --cask fyolo
```

Fyolo 不会自行更新。每次发布都会更新 Homebrew cask，所以一次 `brew upgrade` 就会把它
和你用 Homebrew 装的其他东西一起升到最新版本。如果你装的是磁盘映像，就从 GitHub 下载
新的那个，替换掉旧应用。

## 自带 Agent

Fyolo 不打包编程 Agent——它托管你 Mac 上已有的那些。装上你要用的命令行工具（例如
`claude`、`codex` 或 `amp`），确保它们在 `PATH` 上。Fyolo 会在登录 shell 里启动
每一个，所以你 shell 配置里准备的一切都能用上。

Agent 安装好之后，新建会话时它就会出现在可启动的选项里。另一台机器上的 Agent 也是一样
——Fyolo 会去那儿找它们，并把 hooks 装到那台机器上。见 [设备](/zh-CN/docs/devices)。

## `fyolo` 命令（可选）

Fyolo 附带一个小巧的命令行工具。打开 **设置 ▸ Fyolo server**，开启 **命令行工具**，即可把
`fyolo` 软链到你的 `PATH` 上。之后在任意目录执行 `fyolo` 就会把它作为项目打开，
而 `fyolo sessions …` 让你的 Agent 彼此协作。这完全是可选的——参见
[会话控制与命令行](/zh-CN/docs/session-control)。

## Fyolo 把东西放在哪儿

没有什么是藏着的，也没有什么放在我们的服务器上：

| 路径 | 里面是什么 |
| --- | --- |
| `~/.fyolo/` | 你的配置：`keybindings.json`、`config/agents/` 下的自定义 Agent 清单，以及 `chats/` 草稿目录 |
| `~/Library/Application Support/fyolo/` | 应用状态和你的 `Themes/` 文件夹 |
| `~/.local/bin/` | 你通过 SSH 设置过的机器上的 Fyolo server——`fyolod`，Linux 上还有 `fyolo`。本机上它随应用包一起发布，从不装到这里 |
| 每个 Agent 自己的配置 | Fyolo 的状态 hooks 和它的 `fyolo` 技能，按 Agent 写入 |

## 卸载

退出 Fyolo，运行 `brew uninstall --cask fyolo`；如果装的是磁盘映像，就把它拖进废纸篓。想清掉它写在应用包外面的东西，先在**设置 ▸ Agent** 里关掉
**Agent 实时状态**和**会话控制**——这两个开关会移除它们装在**本机**上的 hooks 和技能，而
你自己写的那些原封不动。然后如果你也想让状态消失，删掉 `~/.fyolo` 和
`~/Library/Application Support/fyolo`。

其他每一台机器上装过的东西都会留在那儿，直到你去那边清理。先把 server 停掉，因为只卸载
服务会留下一个由别的途径启动的 daemon 还在跑：

```bash
fyolod stop
fyolod service uninstall
rm -f ~/.local/bin/fyolod ~/.local/bin/fyolo
```
